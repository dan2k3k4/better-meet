# Security Policy

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Please **don't** open a public issue. Report it privately instead:
[Report a vulnerability](https://github.com/dan2k3k4/better-meet/security/advisories/new).

Include what you found, how to reproduce it, and the impact. You should get a reply within a week. Once a fix is released, you'll be credited in the advisory unless you'd rather not be.
